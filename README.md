# OrbitSpace

OrbitSpace is a personal productivity and learning workspace. It brings task planning, a learning library, and saved resources together in one dashboard.

## Features

- **Dashboard:** View task and favorite-bookmark counts, see priority tasks, and access favorite resources.
- **Tasks:** Create tasks with a description, due date, and priority; filter tasks by priority; and delete them.
- **Learning library:** Save courses with a category, difficulty level, and video URL.
- **Course player:** Watch saved course videos with playback controls. Your playback position is saved so you can resume later.
- **Bookmarks:** Save useful links, search and filter them by type, and mark favorites.

Tasks, courses, bookmarks, and playback progress are stored in the browser’s local storage. They are not synced to a server.

## Tech stack

- React 19 and TypeScript
- Vite
- React Router
- Tailwind CSS
- React Player and Media Chrome
